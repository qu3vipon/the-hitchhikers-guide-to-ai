# AI Agent 시대를 여행하는 히치하이커를 위한 FastAPI 안내서

## 프로젝트 소개

초보자가 AI Agent 개발에 도전하려면 배워야 할 내용이 너무 많습니다. LLM을 이해하는 것만으로는 부족하고, Agent가 사용할 API를 만들기 위해 FastAPI와 데이터베이스, 비동기 프로그래밍까지 익혀야 합니다.

하지만 FastAPI 역시 프로젝트 규모가 커지면서 기존 튜토리얼을 처음부터 따라가기 복잡해졌습니다. 이 책은 처음부터 모든 것을 한꺼번에 설명하지 않습니다. FastAPI 기초에서 출발해 필요한 개념을 차례로 쌓고, LangChain과 LangGraph를 거쳐 **AI Agent 개발까지 혼자 학습**할 수 있도록 돕습니다.

## 주요 독자

다음과 같은 학습자를 주요 독자로 합니다.

- Python 기초 문법을 아는 사람
- LLM에 대한 기본 지식이 있는 사람

두 주제에 익숙하지 않아도 괜찮습니다. 각 챕터에서 **반드시 알아야 하는 내용은 보충 학습으로 함께 제공**하므로, 필요한 부분을 채우며 학습을 이어 갈 수 있습니다.

## 학습 내용

이 책은 아래 순서로 AI Agent 개발에 필요한 핵심 주제를 다룹니다.

1. FastAPI 기초

    FastAPI를 활용해 기본적인 HTTP 요청과 응답을 다루고, API 서버를 만드는 방법을 배웁니다.

2. 비동기 프로그래밍(asyncio)

    다수의 I/O 작업을 효율적으로 처리하기 위한 비동기 프로그래밍 방법을 학습합니다.

3. AI 모델 서빙

    AI 모델을 API 형태로 제공하는 방법을 익힙니다.

4. LangChain & LangGraph

    LLM 애플리케이션과 Agent 워크플로를 구성하는 방법을 배웁니다.

5. AI Agent 개발

    앞에서 학습한 내용을 연결해 AI Agent를 개발합니다.


각 절을 마칠 때마다 **짧은 실습 과제와 정답·해설을 제공**합니다. 직접 구현하고 확인하는 과정을 통해, 다음 단계로 넘어가는 데 필요한 감각을 쌓을 수 있습니다.

자, 그럼 험난한 AI 세계에서 길을 잃지 않고, 나아가 AI Agent를 자유자재로 다루기 위한 첫걸음을 시작해 봅시다.
