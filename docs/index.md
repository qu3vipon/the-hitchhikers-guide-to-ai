# AI Agent 시대를 여행하는 히치하이커를 위한 안내서

## 프로젝트 소개

초보자가 AI Agent 개발에 도전하려면 알아야 할 내용이 많습니다. 기본적으로 LLM을 이해해야 하고, 실제 Agent를 구현하려면 LangChain과 LangGraph를 배워야 합니다. 구현한 Agent를 서비스로 배포하고 운영하려면 FastAPI가 필요하며, 여러 요청과 외부 작업을 효율적으로 처리하기 위해 비동기 프로그래밍도 익혀야 합니다.

그런데 각 기술의 공식 문서를 열어 보면 내용이 너무 많고, 전체적인 학습 흐름도 이어지지 않습니다. FastAPI는 FastAPI대로, Agent 개발은 Agent 개발대로 설명되어 있어 이 기술들이 어떻게 연결되는지 스스로 찾아야 합니다.

따라서 초보자의 이런 어려움을 해결할 수 있도록 이 과정에서는 Agent 개발에 필요한 필수 개념을 순서대로 학습하여 FastAPI 기초부터 비동기 처리, AI 모델 서빙, LangChain과 LangGraph까지 하나의 학습 흐름으로 연결해 AI Agent 개발에 필요한 내용을 연속성 있게 습득합니다.

목표는 단순히 AI Agent를 구현하는 데서 끝나지 않고, **구현한 Agent를 서비스로 배포하고 운영하는 데 필요한 기반까지 함께 학습**합니다.

!!! warning "주의사항"
    AI Agent를 이용해 빠르게 결과물을 만드는 바이브 코딩을 다루는 과정이 아닙니다. Agent를 직접 개발하고, 서비스로 제공하며, 운영하는 방법을 배웁니다.

## 주요 독자

이 과정은 **AI Agent를 직접 개발하고 싶은 학습자**를 위해 만들어졌습니다.

다음 내용을 알고 있으면 더 수월하게 따라올 수 있습니다.

- Python 기초 문법
- 컴퓨터 구조에 대한 기본 지식
- LLM에 대한 기본 지식

하지만 위 주제에 익숙하지 않아도 괜찮습니다. 각 챕터에서 **반드시 알아야 하는 내용은 보충 학습으로 함께 제공**하므로, 필요한 부분을 채우며 학습을 이어 갈 수 있습니다.

## 학습 내용

아래 순서로 AI Agent 개발에 필요한 핵심 주제를 다룹니다.

1. **FastAPI 기초**

    웹 개발(HTTP 요청과 응답)에 대해 알아보고, FastAPI를 활용해 API 서버를 만드는 방법을 배웁니다.

2. **비동기 프로그래밍(asyncio)**

    다수의 I/O 작업을 효율적으로 처리하기 위한 비동기 프로그래밍 방법을 학습합니다.

3. **AI 모델 서빙**

    AI 모델의 특성에 맞게 API 형태로 제공하는 방법을 익힙니다.

4. **LangChain & LangGraph**

    LLM 애플리케이션과 Agent 워크플로를 구성하는 방법을 배웁니다.

5. **AI Agent 개발**

    학습한 내용을 모두 연결해 AI Agent를 개발하고 배포합니다.


각 절을 마칠 때마다 **짧은 실습 과제와 정답·해설을 제공**합니다. 배운 내용을 직접 구현하고 확인하는 과정을 거치며 차근차근 다음 단계로 넘어갑니다.

자, 그럼 험난한 AI 세계에서 길을 잃지 않고, 나아가 AI Agent를 자유자재로 다루기 위한 첫걸음을 시작해 봅시다.
