# 이 과정에서 배우는 것

FastAPI를 활용해 웹 서비스를 구성하는 기본 기술을 배우고, 이를 직접 구현해 봅니다. 단순히 API 문법을 익히는 데서 끝나지 않고, 하나의 서비스가 데이터를 저장하고 사용자와 상호작용하는 과정까지 차례로 따라갑니다.

## 학습 목표 {#learning-goals}

- **웹 서비스 기초**

    인터넷 브라우저가 서버에 요청을 보내고 응답을 받는 과정을 이해합니다. 이 흐름을 바탕으로 FastAPI에서 요청을 받고, 필요한 작업을 수행한 뒤, 응답을 돌려주는 API를 직접 만듭니다.

- **FastAPI CRUD**

    간단한 블로그를 만들어보며 글을 작성하고, 조회하고, 수정하고, 삭제하는 기능을 구현합니다. 이 과정에서 FastAPI를 활용해 데이터를 다루는 CRUD(Create, Read, Update, Delete)의 흐름을 익힙니다.

- **데이터베이스 활용**

    데이터베이스를 활용해 웹 서비스에서 발생하는 데이터를 관리하는 방법을 배웁니다. SQLite와 SQLAlchemy를 활용해 데이터를 저장하고, 조회하고, 변경하는 방법을 배웁니다.

- **회원가입과 로그인**

    사용자가 계정을 만들고 로그인할 수 있도록 회원가입과 인증 기능을 구현합니다. JWT를 이용해 로그인한 사용자를 확인하고, 사용자별 기능을 구분하는 인증 시스템을 구축합니다.

이 과정을 마치면 회원관리 기능을 갖춘 간단한 블로그를 구현하게 됩니다.
