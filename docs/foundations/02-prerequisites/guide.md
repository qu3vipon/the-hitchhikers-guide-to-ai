# 시작하기 전에

웹 개발이 처음인 분들을 위해 FastAPI를 배우기 전에 반드시 알아야 하는 기본 내용을 정리했습니다. 이후 HTTP 요청과 응답, URL, API 같은 용어를 계속 사용하므로, 이 장에서 웹 서비스의 전체 흐름을 먼저 익혀 두면 다음 내용을 이해하기가 한결 수월합니다.

우리의 목표는 AI Agent를 구현하는 데서 그치지 않고, 이를 실제 서비스 형태로 만드는 것입니다. 따라서 FastAPI를 본격적으로 시작하기 전에 **웹 서비스가 어떤 방식으로 동작하는지** 알아둘 필요가 있습니다.

## 어떻게 활용하나요?

- 웹 개발이 처음이라면, 이 장을 처음부터 순서대로 읽어 보세요.
- Python 웹 개발이 익숙하다면, 이 장은 건너뛰고 [**3장 FastAPI 소개**](../03-about.md)부터 시작해도 됩니다.
- 웹 개발 경험은 있지만 Python이 아직 익숙하지 않다면, [**Python 가상환경**](python-virtual-environment.md)부터 살펴보세요.
