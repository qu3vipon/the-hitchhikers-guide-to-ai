# 시작하기 전에

우리의 최종 목표는 AI Agent를 구현하는 데서 그치지 않고, 이를 실제 서비스 형태로 만드는 것입니다. 따라서 과정을 본격적으로 시작하기 전에 개발 환경을 구축하는 방법, 웹 개발의 기본 흐름, Python 개발 환경, LLM 기초처럼 반드시 알고 있어야 하는 배경 지식을 가볍게 정리합니다.

!!! supplement "보충 학습"
    **사전 학습**은 AI Agent 개발에 필요한 배경지식을 보충하는 내용입니다. 이미 익숙한 내용은 가볍게 훑거나 건너뛰어도 괜찮습니다. 이미 알고 있는 내용인지 점검하고 싶다면 각 페이지의 실습 과제만 풀어 봐도 좋습니다.

## 어떻게 활용하나요? {#how-to-use}
각 내용은 다음 주제로 자연스럽게 이어지도록 구성했으므로, 처음 학습한다면 목차 순서에 따라 읽어 보세요.

- 프로그래밍 자체가 처음이라면, [**터미널**](terminal.md)부터 시작해 하나씩 따라가 보세요.
- 웹 개발이 처음이라면, [**웹 서비스란?**](web-service.md)부터 시작하세요.
- 웹 개발 경험은 있지만 Python이 아직 익숙하지 않다면, [**Python 가상환경**](python-virtual-environment.md)부터 살펴보세요.
- Python 웹 개발 경험이 있다면, 사전 학습은 건너뛰고 [**FastAPI 기초**](../fastapi/01-introduction/what-you-learn.md)로 넘어가도 됩니다.
