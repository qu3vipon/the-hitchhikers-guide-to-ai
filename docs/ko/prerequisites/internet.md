# 인터넷

인터넷(Internet)이란 무엇일까요? 인터넷은 **여러 네트워크가 서로 연결된 네트워크**입니다.

예를 들어 내 컴퓨터는 집 안의 공유기와 연결되어 작은 네트워크를 이룹니다. 공유기는 통신사의 네트워크와 연결되고, 이 통신사 네트워크는 다시 다른 통신사의 네트워크와 이어집니다. 이렇게 연결은 계속 확장되어 지역을 넘어 다른 나라의 통신사와 네트워크까지 확장됩니다. 이처럼 **크고 작은 네트워크가 여러 겹으로 연결된 구조**가 바로 인터넷입니다.

## 데이터의 이동 {#data-movement}

Wi-Fi 같은 **무선 통신**은 컴퓨터나 스마트폰과 공유기 사이처럼 비교적 짧은 거리를 연결할 때 사용합니다. 반면 지역과 국가를 넘어 데이터를 전달하려면 더 멀리, 더 안정적으로 연결할 수 있는 유선 네트워크가 필요합니다.

통신사 네트워크의 연결이 국가와 대륙을 넘어서 이어질 때는 바다 밑에 설치된 **해저 케이블**이 중요한 역할을 합니다. 국가와 대륙 사이의 데이터는 대부분 이 해저 케이블을 통해 이동합니다. 해저 케이블 안의 광섬유에서는 데이터가 아주 빠른 빛 신호로 전달됩니다.

이처럼 우리가 일상에서 사용하는 인터넷은 Wi-Fi 같은 무선 통신 기술과 스마트폰이나 컴퓨터 같은 단말 장치, 케이블과 공유기 같은 다양한 장비들이 서로 연결되어 함께 동작합니다.

## 데이터 교환 {#data-exchange}

인터넷이 존재하는 가장 근본적인 이유는 멀리 떨어진 컴퓨터끼리 **데이터를 교환하기 위해서**입니다. 메시지, 사진, 동영상, 웹 페이지, AI Agent의 답변까지 인터넷을 통해 오가는 모든 것은 결국 데이터입니다.

따라서 인터넷 기반의 웹 서비스에서는 데이터를 어떻게 잘 주고 받을 지가 중요합니다. 이를 위해 인터넷과 웹은 데이터를 교환하는 여러 방식과 약속을 발전시켜 왔습니다.

!!! info "초기 인터넷의 데이터 교환"
    1969년, 미국 UCLA와 스탠퍼드 연구소 사이에 원격으로 컴퓨터에 접속하는 첫 메시지를 보내는 실험이 있었습니다. `LOGIN`을 보내려 했지만 시스템이 중간에 멈춰, 처음 전달된 메시지는 `LO` 두 글자였다고 알려져 있습니다.
