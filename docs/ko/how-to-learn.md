# 학습 방법

## 학습 내용 분류 {#learning-content-types}

학습 내용은 중요도에 따라 아래와 같이 분류됩니다. 현재 이해도와 학습 목표에 맞춰 필요한 내용은 충분히 읽고, 이미 알고 있는 내용은 가볍게 넘어가도 좋습니다.

### :material-check-circle: <span class="learning-label learning-label--required">필수 학습</span> {#required-learning}

이어지는 과정을 이해하거나 실습을 진행하는 데 꼭 필요한 내용입니다. 처음부터 순서대로 따라가고, 예제 코드도 직접 실행해 보는 것을 권장합니다.

### :material-plus-circle-outline: <span class="learning-label learning-label--supplement">보충 학습</span> {#supplementary-learning}

Python, 웹 개발, LLM처럼 배경지식이 필요한 부분을 짧게 보충하는 내용입니다. 이미 익숙한 주제라면 가볍게 훑거나 건너뛰어도 괜찮습니다. 학습 중 이해가 잘되지 않는 부분이 생기면 다시 돌아와 확인하세요.

### :material-star-outline: <span class="learning-label learning-label--optional">선택 학습</span> {#optional-learning}

핵심 흐름을 확장하거나 더 깊이 이해하기 위한 내용입니다. 지금 바로 이해되지 않거나, 지금은 자세히 살펴볼 필요를 느끼지 않는다면 우선 넘어가도 괜찮습니다. 필요해졌을 때 다시 돌아와 학습할 수 있습니다.

### :material-pencil: <span class="learning-label learning-label--exercise">실습 과제</span> {#exercises}

각 절의 끝에는 짧은 실습 과제가 있습니다. 먼저 스스로 구현해 본 뒤 정답·해설을 확인하세요. 정답과 다른 방식으로 구현했더라도, 의도한 기능이 동작하고 그 이유를 설명할 수 있다면 충분합니다.

## 실습 환경 {#practice-environment}

이 과정에서 안내하는 터미널 명령어는 기본적으로 macOS를 기준으로 작성합니다. 하지만 Windows에서도 동일하게 학습할 수 있으며, 운영체제에 따라 달라지는 명령어는 Windows용 명령어를 함께 제공합니다.
