# 확률로 단어를 예측하기 {#probabilistic-word-prediction}

Word2Vec은 주변 단어나 가운데 단어를 바탕으로 어떤 단어가 등장할지를 예측하는 모델입니다. 하지만 모델이 처음부터 “커피”처럼 하나의 답을 바로 고르는 것은 아닙니다. 먼저 후보가 되는 모든 단어에 대해 각각의 점수를 계산합니다. 이때 모델이 예측할 수 있는 단어들의 목록을 **단어집(vocabulary)**이라고 합니다. Word2Vec은 기본적으로 이 단어집에 없는 단어를 직접 예측할 수 없습니다.

따라서 기본적인 Word2Vec에서는 출력층의 뉴런 수가 단어집에 포함된 단어 수와 같습니다. 예를 들어 `10,000`개의 단어가 있다면 출력층에도 `10,000`개의 뉴런이 있고, 각 뉴런은 하나의 단어에 대응합니다.

![word2vec 모델이 단어집의 모든 후보에 점수를 출력하는 모습](../assets/images/word2vec-output-layer.svg){ .neural-network-image }

출력층은 단어집에 든 단어 수만큼 값을 만듭니다. 이 값은 각 단어가 현재 문맥에 얼마나 어울리는지를 나타내는 정규화되지 않은 점수이며, **로짓(logit)**이라고 부릅니다.

로짓은 음수가 될 수도 있고, 모두 더해도 `1`이 되지 않기 때문에 그대로 확률로 해석할 수 없습니다. 이를 모든 후보에 대한 확률 분포로 바꾸기 위해 [활성화 함수](03-perceptron.md#mechanical-decision-making)를 사용하며, 출력층에는 주로 **소프트맥스(softmax)**를 적용합니다.

소프트맥스는 각 로짓을 `0`과 `1` 사이의 값으로 바꾸고, 모든 단어의 값을 더하면 `1`이 되도록 조정합니다. 따라서 각 값은 현재 문맥에서 해당 단어가 나올 가능성으로 해석할 수 있습니다.
