# 언어는 확률적 패턴을 따른다

## 자연어의 규칙과 패턴 {#patterns-in-natural-language}

사람이 일상에서 말하고 쓰는 한국어, 영어처럼 자연스럽게 발달한 언어를 **자연어(natural language)**라고 합니다. 프로그래밍 언어처럼 사람이 명확한 규칙을 설계한 언어와 구분하는 말입니다.

자연어에서 단어는 완전히 무작위로 이어지지 않습니다. 예를 들어 “나는 아침마다 ___ 마신다”라는 문장에서 “커피를”은 자연스럽지만, “자동차를”은 어울리지 않습니다. 이처럼 문맥에 따라 어떤 단어가 등장할 가능성이 높은지가 달라집니다.

문법도 언어의 중요한 패턴입니다. “나는 아침마다 커피를 마신다”는 자연스러운 문장이지만, “마신다 아침마다 나는 커피를”은 어순이 어색합니다. 이는 단어의 순서와 조사·어미의 사용에도 일정한 규칙이 있기 때문입니다.

초기 자연어 처리에서는 사람이 언어의 문법과 의미 규칙을 일일이 정의하고 프로그램에 직접 구현하는 방식을 사용했습니다. 예를 들어 문장에서 주어와 서술어를 구분하거나, 단어의 의미를 판단하는 규칙을 사람이 직접 만들어야 했습니다.

하지만 자연어에는 다양한 표현과 예외가 존재하고, 문맥에 따라 뜻도 달라집니다. “배가 아프다”의 ‘배’는 몸의 부위를 의미하지만, “배가 항구를 떠난다”의 ‘배’는 탈것을 의미합니다. 이처럼 같은 단어도 문맥에 따라 의미가 달라질 수 있기 때문에 사람이 언어의 모든 경우를 규칙으로 빠짐없이 정의하는 데에는 한계가 있습니다.

![같은 단어 배가 문맥에 따라 몸의 부위 또는 탈것을 의미하는 모습](../assets/images/llm/07-context-meaning.svg){ .neural-network-image }

반면 사람이 실제로 언어를 배우는 과정은 이와 다릅니다. 우리는 언어의 규칙을 모두 배운 뒤 말을 시작하지 않습니다. 문법을 배우기 전부터 수많은 문장을 듣고 사용하면서, 어떤 표현이 자연스러운지, 어떤 단어들이 함께 쓰이는지와 같은 **언어의 패턴을 자연스럽게 익힙니다.** 문법은 이렇게 언어에서 발견되는 규칙성을 정리하고 설명한 체계라고 볼 수 있습니다.

이처럼 사람들이 사용하는 언어에는 일정한 확률적 패턴이 존재합니다. 어떤 문맥 뒤에 어떤 말이 이어질지가 하나로 정해져 있지는 않지만, 어떤 표현은 다른 표현보다 훨씬 자주 나타납니다. 언어를 다루는 인공지능은 이러한 특성을 활용합니다. 문법을 프로그램으로 직접 구현하는 대신, 방대한 텍스트를 학습하면서 **언어에 숨어 있는 확률적 패턴을 데이터로부터 찾아내는 것**입니다.

## 문맥으로 예측하기 {#context}

[Word2Vec](06-word-embeddings.md/#learning-from-context)은 주변 단어나 가운데 단어를 바탕으로 어떤 단어가 등장할지를 예측하는 모델이라고 했습니다. 하지만 모델이 처음부터 “커피”처럼 하나의 답을 바로 고르는 것은 아닙니다. 먼저 후보가 되는 모든 단어에 대해 각각의 점수를 계산합니다. 이때 모델이 다루는 단어들의 목록을 **어휘집(vocabulary)**이라고 합니다. Word2Vec은 기본적으로 이 어휘집에 없는 단어를 직접 예측할 수 없습니다.

기본적인 Word2Vec에서 전체 어휘집을 대상으로 예측한다면 출력층의 뉴런 수는 어휘집에 포함된 단어 수와 같습니다. 예를 들어 `10,000`개의 단어가 있다면 출력층에도 `10,000`개의 뉴런이 있고, 각 뉴런은 하나의 단어에 대응합니다.

![Word2Vec 모델이 어휘집의 모든 후보에 점수를 출력하는 모습](../assets/images/llm/07-word2vec-output-layer.svg){ .neural-network-image .language-modeling-image }

“아침마다”와 “마신다”를 이용해 그 사이에 들어갈 단어를 예측한다고 해 봅시다.

출력층은 어휘집에 포함된 단어 수만큼 값을 만듭니다. 출력층의 각 뉴런에서 계산되는 값은 해당 단어가 현재 문맥에 얼마나 어울리는지를 나타내는 점수이며, 이를 **로짓(logit)**이라고 합니다.

로짓은 후보 단어 사이의 상대적인 점수이지만, 값의 범위가 정해져 있지 않아 확률로 직접 해석할 수는 없습니다. 따라서 로짓을 **확률로 변환하면 각 단어가 선택될 가능성**을 나타낼 수 있고, 이를 실제 정답과 비교하여 모델을 학습할 수 있습니다.

이때 로짓을 확률로 바꾸기 위해 **소프트맥스(softmax)**라는 [활성화 함수](03-perceptron.md/#mechanical-decision-making)를 사용합니다. 소프트맥스는 모든 로짓을 함께 계산해 각 값을 `0`과 `1` 사이로 변환하고, 전체 합이 `1`이 되도록 합니다. 점수가 높은 후보에는 더 큰 확률을, 낮은 후보에는 더 작은 확률을 부여해 어떤 단어가 등장할 가능성이 높은지를 하나의 확률 분포로 나타냅니다. 예시에서는 “커피”의 확률이 `0.68`로 가장 높으므로, 모델은 “커피”를 가장 가능성 높은 단어로 예측합니다.

그렇다면 신경망은 단어를 예측하는 방법을 어떻게 배울까요?

신경망은 실제 문장에 등장한 단어를 정답으로 삼아 자신의 예측과 비교하면서 학습합니다. 이를 위해 수많은 문장을 학습 데이터로 사용합니다. 이처럼 언어를 분석하거나 모델을 학습하기 위해 모아 놓은 텍스트 자료를 **코퍼스(corpus, 말뭉치)**라고 합니다.

학습 데이터에는 실제 문장이 있으므로 “아침마다”와 “마신다” 사이에 어떤 단어가 들어갔는지 이미 알고 있습니다. 모델은 **자신이 예측한 확률 분포를 실제 정답과 비교**하고, 예측이 정답과 얼마나 다른지를 [손실 함수](03-perceptron.md/#learning-goal)로 계산합니다.

이때 대표적으로 사용하는 손실 함수가 **크로스 엔트로피(cross entropy)**입니다. 크로스 엔트로피는 모델이 정답 단어에 얼마나 높은 확률을 부여했는지를 바탕으로 손실을 계산합니다. 정답에 높은 확률을 부여할수록 손실은 작아지고, 낮은 확률을 부여할수록 손실은 커집니다.

모델은 이렇게 계산한 손실을 줄이는 방향으로 단어 벡터를 조금씩 조정합니다. 이 과정을 반복하면서 실제 데이터에 나타나는 언어의 패턴을 학습하고, 문맥에 어울리는 단어를 점차 더 정확하게 예측하게 됩니다.

## 단어 쪼개기 {#tokens}

지금까지는 이해하기 쉽게 “단어”를 기준으로 설명했지만, 실제로 언어를 다루는 모델은 텍스트를 **토큰(token)**이라는 처리 단위로 나눕니다. 토큰은 하나의 완전한 단어일 수도 있고, 단어의 일부나 기호일 수도 있습니다. 예를 들어 “아침마다 커피를 마신다.”는 `[아침] [마다] [커피] [를] [마신] [다] [.]`처럼 여러 토큰으로 나눌 수 있습니다.

문장을 단어 단위로만 나누면 어휘집이 지나치게 커질 수 있습니다. 같은 단어도 다양한 형태로 변하고 새로운 단어도 계속 등장하기 때문입니다. 예를 들어 `마시다`라는 기본형에서 `마신다`, `마셨다`, `마시겠지만`처럼 여러 표현이 만들어집니다. 이러한 표현을 모두 별개의 단어로 등록하면 어휘집의 크기가 빠르게 늘어납니다.

이를 해결하기 위해 많은 언어 모델은 **자주 등장하는 글자나 단어의 일부를 토큰으로 사용**합니다. 예를 들어 `마신다`, `마셨다`, `마시겠지만`을 각각 하나의 단어로 등록하는 대신, 여러 표현에서 공통으로 사용되는 조각과 나머지 부분을 나누어 토큰으로 표현할 수 있습니다. 이렇게 하면 같은 조각을 반복해서 등록하지 않고도 다양한 표현을 조합할 수 있습니다.

![여러 표현에서 반복되는 조각을 공유하는 토큰화 예시](../assets/images/llm/07-shared-token-pieces.svg){ .neural-network-image }

앞에서 살펴본 것처럼 전체 어휘집을 대상으로 예측하는 모델에서는 어휘집의 크기가 출력층의 뉴런 수와 계산량에도 영향을 줍니다. 따라서 토큰화는 **어휘집의 크기를 제한하면서도 다양한 표현을 처리할 수 있게** 하는 중요한 과정입니다.

토큰을 나누는 방식은 언어의 구조와 토큰화 방법에 따라 달라집니다. 영어는 띄어쓰기가 단어의 경계를 비교적 잘 보여 주지만, 한국어는 조사와 어미가 붙고 한 단어 안에서도 형태가 다양하게 바뀝니다. 따라서 언어의 특성과 학습 데이터에 따라 같은 문장도 서로 다른 방식으로 토큰화될 수 있습니다.

예를 들어 “커피를 마셨습니다”와 영어 표현인 “I drank coffee”를 비교해 봅시다. 띄어쓰기를 기준으로 보면 한국어는 `커피를`과 `마셨습니다` 두 어절이고, 영어는 `I`, `drank`, `coffee` 세 단어입니다. 하지만 토큰화 과정에서는 단어의 일부가 별도의 토큰으로 나뉠 수도 있습니다.

![한국어와 영어 문장을 토큰으로 나눈 예시](../assets/images/llm/07-korean-english-tokens.svg){ .neural-network-image }

앞에서 살펴본 임베딩, 어휘집, 로짓, 확률 분포 역시 실제 언어 모델에서는 단어가 아닌 토큰을 기준으로 이해하면 됩니다. 이러한 내용을 종합하면 신경망이 텍스트를 처리하는 일반적인 흐름을 다음과 같이 정리할 수 있습니다.

![텍스트가 토큰화와 임베딩을 거쳐 다음 토큰을 예측하는 과정](../assets/images/llm/07-language-modeling-flow.svg){ .neural-network-image .language-modeling-image }

## Word2Vec이 남긴 것 {#word2vec-significance}

Word2Vec은 오늘날의 LLM에 핵심 구성 요소로 직접 사용되지는 않습니다. 하지만 단어의 의미와 관계를 벡터로 학습할 수 있다는 가능성을 보여 준 대표적인 초기 모델입니다.

이후 단어의 표현을 학습하는 방법은 단어마다 하나의 고정된 벡터를 부여하는 방식에서 더 나아갔습니다. 같은 단어라도 앞뒤 문맥에 따라 서로 다른 벡터로 표현하는 방법이 발전했고, 이러한 문맥을 반영한 표현 학습은 현대 언어 모델의 중요한 기반이 되었습니다. 앞으로 살펴볼 트랜스포머 기반 언어 모델 역시 문맥에 따라 단어의 표현을 만들어 냅니다.

## :material-pencil: 실습 과제 {#exercises}

다음 문장이 맞으면 O, 틀리면 X를 선택하세요.

1. 자연어에서 다음에 올 표현은 완전히 무작위로 정해진다.
2. Word2Vec의 출력층은 어휘집의 후보마다 하나의 로짓을 계산한다.
3. 소프트맥스를 적용한 뒤 각 후보의 확률을 모두 더하면 `1`이 된다.
4. 하나의 단어는 언제나 하나의 토큰으로만 나뉜다.
5. 크로스 엔트로피는 모델이 예측한 확률 분포와 실제 정답의 차이를 손실로 계산한다.

??? success "정답·해설"
    1. **X** — 자연어에는 문맥에 따라 어떤 표현이 더 자주, 자연스럽게 이어지는지에 관한 확률적 패턴이 있습니다.
    2. **O** — Word2Vec은 어휘집에 든 모든 후보에 점수를 계산하고, 이 점수를 로짓이라고 합니다.
    3. **O** — 소프트맥스는 모든 로짓을 확률로 바꾸며, 전체 합이 `1`이 되도록 조정합니다.
    4. **X** — 토큰은 단어 전체일 수도 있지만, 단어의 일부·띄어쓰기·기호일 수도 있습니다.
    5. **O** — 크로스 엔트로피는 예측한 확률 분포가 실제 정답과 얼마나 다른지 계산해 학습의 손실로 사용합니다.
