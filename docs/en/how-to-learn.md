# How to learn

## Types of learning material {#learning-content-types}

The material is grouped into the categories below to help you decide where to focus. Spend more time on what you need for your goals, and feel free to skim topics you already know.

### :material-check-circle: <span class="learning-label learning-label--required">Core material</span> {#required-learning}

These sections cover what you need to understand the topics that follow or complete the exercises. We recommend working through them in order and running the example code yourself.

### :material-plus-circle-outline: <span class="learning-label learning-label--supplement">Background reading</span> {#supplementary-learning}

These sections provide a brief introduction or refresher on background topics such as Python, web development, and LLMs. If you are already comfortable with a topic, you can skim or skip it. Come back whenever you encounter something you need to brush up on.

### :material-star-outline: <span class="learning-label learning-label--optional">Further exploration</span> {#optional-learning}

These sections go beyond the main learning path to broaden or deepen your understanding. If something does not click yet, or you do not need that level of detail right now, feel free to move on. You can return when it becomes useful.

### :material-pencil: <span class="learning-label learning-label--exercise">Exercises</span> {#exercises}

Each section ends with a short exercise. Try it yourself before checking the answer and explanation. For coding exercises, your solution does not have to match the example: what matters is that it works as intended and you can explain why.

## Your practice environment {#practice-environment}

The terminal commands in this guide use macOS as the default. You can also follow along on Windows; whenever a command differs between operating systems, we provide the Windows version as well.
