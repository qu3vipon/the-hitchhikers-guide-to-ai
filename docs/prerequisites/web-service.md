# 웹 서비스란?

우리는 일상에서 다양한 웹 서비스를 익숙하게 사용합니다. 하지만 정작 웹이 무엇인지, 웹 서비스가 어떤 의미인지 깊이 생각해 본 적은 많지 않습니다. 누군가 웹이 무엇인지 묻는다면, 어디서부터 말해야 할지 막막합니다. 먼저 웹 서비스란 무엇인지 알아봅시다.

## 웹(Web)이란?

웹(Web)은 영어로 거미줄이나 그물처럼 얽힌 구조를 뜻합니다. 인터넷에 흩어진 수많은 문서가 링크를 통해 서로 연결된 모습이 마치 거미줄과 닮았다고 해서, 이처럼 **문서들이 서로 연결된 구조를 웹(Web)**이라고 부릅니다.

인터넷 브라우저를 열어 웹 사이트에서 정보를 찾고 다른 페이지로 이동하는 일은 모두 웹 위에서 이루어집니다. 이런 웹은 HTML, HTTP, URL 같은 여러 기술이 서로 맞물려 동작합니다. 웹을 구성하는 구체적인 기술은 이후에 하나씩 자세히 살펴보겠습니다.

!!! tip "www란?"
    웹 주소 앞에서 자주 보이는 `www`는 전 세계에 걸쳐 연결된 웹을 뜻하는 **World Wide Web**의 약자입니다.

## 서비스(Service)란?

서비스는 **누군가의 필요를 해결하기 위해 제공하는 기능이나 활동**입니다. 카페에서 음료를 주문해 받는 일, 은행에서 계좌를 만들고 송금하는 일, 도서관에서 책을 빌리는 일도 모두 서비스의 예입니다.

서비스에는 보통 **이용자의 요청**^1^이 있고, 그 요청을 **처리하는 과정**^2^과 **결과**^3^가 있습니다.

예를 들어

- 카페에서는 주문을 받고^1^, 음료를 만들어^2^, 손님에게 제공^3^합니다.
- 은행에서는 고객의 송금 요청^1^을 받아, 돈을 이체^2^한 다음, 송금확인증을 발행^3^합니다.

## 웹 서비스란?

따라서 웹 서비스는 **사용자의 필요를 해결하는 기능을 인터넷을 통해 이용할 수 있도록 구현한 서비스**입니다. 사용자는 보통 웹 브라우저나 앱으로 서비스에 접속해 필요한 기능을 이용합니다.

이전까지는 오프라인에서 직접 방문해야 이용할 수 있던 서비스들이 인터넷을 통해 언제 어디서나 손쉽게 사용 가능해졌습니다.

예를 들어 우리 주변에는 다음과 같은 웹 서비스가 있습니다.

- 채팅 서비스 → 카카오톡
- 전자상거래 서비스 → 쿠팡
- 금융 서비스 → 토스
- 중고거래 서비스 → 당근마켓

우리의 최종 목표는 AI Agent를 만들고, 이를 인터넷을 통해 사용할 수 있는 웹 서비스 형태로 제공하는 것입니다. 그렇기 때문에 Agent를 구현하는 방법뿐 아니라, 웹 서비스의 구조도 함께 알아야 합니다.

## 실습 과제

다음 문장이 맞으면 O, 틀리면 X를 선택해 보세요.

1. 웹은 인터넷에 있는 문서들이 링크로 연결된 구조를 뜻한다.
2. 웹 서비스는 웹 브라우저에서만 이용할 수 있다.
3. 서비스는 이용자의 요청을 처리하고 결과를 제공하는 과정으로 이루어진다.

??? note "정답 및 해설"
    1. **O** — 문서들이 링크로 연결된 구조를 웹이라고 한다.
    2. **X** — 웹 서비스는 브라우저뿐 아니라 모바일 앱 같은 다양한 형태의 프로그램에서도 이용할 수 있다.
    3. **O** — 서비스는 요청, 처리 과정, 결과의 흐름으로 이해할 수 있다.
