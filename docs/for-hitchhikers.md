# 히치하이커를 위하여

말 한마디면 AI가 코드를 만들고 서비스까지 배포할 수 있는 시대입니다. 이런 시대에 개념을 하나씩 이해하고 직접 구현하며 배우는 일이 여전히 의미가 있을까 하는 질문이 있을 수 있습니다.

그런데 AI를 더 잘 활용하기 위해서는 반드시 **스스로 생각하는 힘**이 필요하다고 믿습니다. AI는 빠르게 초안을 만들고, 막힌 부분의 힌트를 주고, 여러 선택지를 제안해 줄 수 있습니다. 하지만 무엇을 만들지 정하고, 결과가 정말 원하는 방향인지 판단하고, 문제가 생겼을 때 다음 질문을 찾아가는 일까지 대신해 주지는 않습니다.

이 안내서 역시 AI와 함께 만들어지고 있습니다. 자료를 조사하고 문장을 다듬는 과정에서 AI의 도움을 받습니다. 다만 이 과정에서 어떤 내용을 왜 배워야 하는지, 어떤 순서로 연결할지, 학습자에게 무엇이 꼭 필요한지를 판단하는 일은 제가 결정합니다. 우리는 AI를 도구로 활용하되, 무엇을 만들고 어떤 선택을 할지에 대해서는 **자신만의 뚜렷한 취향과 기준**을 가져야 합니다.

빠르게 결과물을 만드는 방법도 분명 배워야합니다. 하지만 다른 한편에는 여전히 **스스로 고민하고, 이해하고, 깨우치며 배우고 싶은 사람들**도 있습니다. 이 안내서는 그런 사람들, AI 시대라는 넓고 낯선 세계에서 길을 잃지 않으려는 히치하이커를 위해 만들었습니다.

혼자서도 차근차근 따라갈 수 있는, 믿을 만한 학습 콘텐츠를 무료로 제공하고 싶습니다. 이 안내서가 여러분이 다음 질문을 찾고, 직접 답을 만들어 가는 여정에 작은 도움이 되기를 바랍니다.
